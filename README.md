# Personal Expense Tracker

A Python-based personal expense tracker that uses CSV files for data storage.

## Features

- Add expenses with name, category, amount, and date
- View all recorded expenses
- Calculate total spending
- View category-wise spending
- Find the highest expense
- Store expense data permanently using a CSV file
- Simple menu-driven command-line interface

## Technologies Used

- Python
- CSV
- Lists and Dictionaries
- File Handling
- Functions
- Conditional Statements and Loops

## How to Run

1. Make sure Python is installed.
2. Download or clone this repository.
3. Open the project folder in VS Code or a terminal.
4. Run:

```bash
python expense_tracker.py
